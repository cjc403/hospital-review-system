# 指标包与计分规则

本文给出等级评审第一套指标包的样例口径、年度合并规则和计分测试向量。表名、字段名、原因码以 [01-详细设计说明书.md](01-详细设计说明书.md) 为准。若例子与说明书的枚举冲突，以说明书为准，并改例子。

样例不是 203 条全文。引擎验收用这些指标即可。正式国标清单在实施时按 `clause` 和 `indicator_def` 录入，不改变本文的计分函数。

## 1. 指标元数据

每条可计算指标对应 `indicator_def` 的一个版本。字段含义见说明书第 5.2 节。编写时遵守：

- 给人读的分子、分母、纳入、排除放在文本字段。SQL 放在 `sql_template`，只查主题表白名单。
- 编码列表放在 `code_set` / `code_set_item`，SQL 用参数 `code_set_id` 连接，不把编码写死在字符串里。
- `sql_status` 为 `confirmed` 之前，月结跳过该版本。
- 空分母：`value` 为空，`light = na`，不参与符合比例。
- 灯号用 `indicator_target`，与计分无关。计分只用 `score_type`、方向和阈值。

年度如何从月得到，由 `annual_agg` 决定，在一期年度任务里完成，不在计分函数里完成：

| annual_agg | 年度事实 |
| --- | --- |
| year_end_snapshot | 取该年 12 月的分子、分母和值。用于人员比、床位规模 |
| month_avg | 取该年各月值的算术平均。某月 `na` 则不进入平均，若 12 个月全是 `na`，年度为 `na` |
| drg_formula | 不平均各月指数。按第 3 节公式，用该年 `drg_group` 直接汇总 |

`fact_member` 在月批次和年批次都要写。明细页只读清单，不重放 SQL。见说明书第 5.3 节。

## 2. 计分函数

一期只生产年度 `indicator_fact`，不调用本节函数。二期 `score_run` 对选用集中的每个 `national_indicator_code` 调用一次。

### 2.1 输入与输出

输入：

- `score_type`：`all_or_nothing` 或 `interval_trend`
- `direction`：`high` 或 `low`
- `years`：按年份升序的年度值列表，长度 1 到 4。值为空的年份视为该年 `na`，从列表中去掉。去掉后长度为 0，则输出 `not_applicable`
- `threshold`：达标线。`interval_trend` 必须有达标线或分档表。都没有时，选用集审批拒绝该指标，函数不被调用
- `last_year_value`：原始最后一年的值，规模类跨年时单独判断，即使它也在 `years` 里

输出：

- `merged_value`
- `conform`：布尔或空（不适用）
- `reason_code`：`pass`、`median`、`median_fail`、`worst_year`、`last_year_fail`、`not_applicable`
- `year_count`：去掉 `na` 之后的年数

`year_count < 4` 时函数仍计算。调用方把 `score_run.trial` 置为 true。

### 2.2 中位数

将数值升序排列。奇数个取正中间。偶数个取中间两个的算术平均。不存在「中位数所在的那一年」。

例：2、4、9、10 的中位数是 (4+9)/2 = 6.5。

### 2.3 规模类与配比类

`score_type = all_or_nothing`。

单年：值达到 `threshold`（高优为大于等于，低优为小于等于，比较符以 `indicator_target.comparator` 为准，样例默认高优 `ge`、低优 `le`）则 `conform = true`，`reason_code = pass`。否则 `conform = false`，`reason_code = median_fail`。单年时中位数就是该年本身。

跨年同时满足下面两条才符合，`reason_code = pass`：

1. 中位数达到标准。否则 `reason_code = median_fail`，`conform = false`。
2. 最后一年达到标准。中位数已达标但最后一年未达标时，`reason_code = last_year_fail`，`conform = false`。

`merged_value` 取中位数，不取最后一年。界面用原因码说明最后一年的问题。

### 2.4 连续监测

`score_type = interval_trend`。

先判断趋势。管理方向：高优希望上升或持平，低优希望下降或持平。从第一年到最后一年，若后一年相对前一年变坏的次数多于变好的次数，视为趋势与管理方向相反。变好与变坏次数相同，或只有一年，视为非变差。

- 非变差：`merged_value` 取中位数。指标上若另行注明合并方式为平均数，则改取平均。样例默认中位数。`reason_code = median`。再用合并值对照 `threshold` 得到 `conform`。
- 变差：`merged_value` 取最差年。高优取最小，低优取最大。`reason_code = worst_year`。用最差年的值对照 `threshold` 得到 `conform`。

分档表 `band_json` 若存在，符合与否看合并值落在哪一档。档上的符合标记由省细则配置。样例只用单条阈值，不用分档。

### 2.5 其他规则

- 政策或编码版本在周期中发布：该指标从发布后的下一个完整年开始进入 `years`。发布当年不进入。由调用方在组 `years` 之前过滤，函数不读政策日期。
- 未开展的限制类技术和单病种在 `selection_exclusion` 中。调用方不把它们送进函数，也不计入 `included_count`。
- 符合比例 = 符合的国标指标数 / 纳入的国标指标数。同一 `national_indicator_code` 下拆出的例数和发生率只计一次。调用前先选定该编码下用于计分的那一个 `indicator_def`，发生率优先于例数。
- 比例不低于 0.90、0.80、0.70 分别为甲、乙、丙。前置任一条 `compliance = non_compliant`，或条款抽查错误率大于 0.10，等次改为延期评审。监测比例仍返回。

错误率的定义在说明书第 8 节，不在本函数内计算。

## 3. 样例口径

下列编码供测试和种子数据使用。`pack_code` 均为 `grade_review`。责任部门是假设，实施时按医院职责改 `owner_dept`，不改公式。

### 3.1 开放床位使用率 `IND-BED-USE`

- 方向 `high`，`score_type = interval_trend`，`grain = month`，`annual_agg = month_avg`，`collect_mode = auto`
- 分子：统计期内 `bed_day.occupied_bed_day` 之和
- 分母：同期开放床日之和。按日存储时，当日开放床日等于当日 `open_bed`
- 时间字段：`stat_date`
- 全院 `ALL` 含未对照科室的床日。科室行跳过 `std_dept_code` 为空的行，那些床日仍进入 `ALL`
- `fact_member`：床位不是出院患者。成员清单允许为空，血缘写 `bed_day` 的日期范围和行数。明细页显示「本指标无患者清单」

### 3.2 全院护士与开放床位比 `IND-NURSE-BED`

- 方向 `high`，`all_or_nothing`，`grain = month`，`annual_agg = year_end_snapshot`
- 分子：`staff_month` 中岗位为护士的 `on_duty_count` 全院合计。取月末快照，禁止把 12 个月人数相加，也禁止用日均人数
- 分母：同一月末全院开放床位。取 `bed_day` 在该月最后一天的 `open_bed` 之和
- 年度事实取 12 月，不取月均

### 3.3 手术患者住院死亡率 `IND-SURG-DEATH`

- 方向 `low`，`interval_trend`，`month`，`month_avg`
- 分子：`visit_discharge.is_surgery` 且 `is_death` 的出院人数
- 分母：`is_surgery` 的出院人数
- 主索引为空仍然计入。科室未对照计入 `ALL` 和 `UNMAPPED`
- `fact_member`：分母写全部手术出院的住院号和出院日期；分子写其中死亡的

### 3.4 低风险病种住院死亡率 `IND-LOWRISK-DEATH`

- 方向 `low`，`interval_trend`，`month`，`month_avg`
- 分母：主要诊断（`dx.dx_type = main`）命中低风险 `code_set` 的出院患者
- 分子：分母中 `is_death` 的人数
- 不在 `visit_discharge` 上预写低风险标记。编码集版本写进血缘 `filter_summary`

### 3.5 出院患者四级手术占比 `IND-OP-L4`

- 方向 `high`，`interval_trend`，`month`，`month_avg`
- 分子：`oper.oper_level = 4` 的出院患者人数。同一出院记录多条四级手术只计 1 人
- 分母：`visit_discharge` 出院人数

### 3.6 出院后 0–31 天非预期再住院率 `IND-READMIT-31`

- 方向 `low`，`interval_trend`，`month`，`month_avg`
- 分母：本期出院、`is_death = false`、且 `empi` 非空的人数
- 分子：分母中，`empi` 相同、下一次入院日期减去本次 `discharge_date` 在 0 到 31 天的人数
- `empi` 为空的出院患者不进分子和分母。人数写入 `indicator_fact.excluded_count`，并写 `anomaly.kind = empi_missing`
- 跨月：分子判定要能读到本期出院之后 31 天内的入院。月结若在次月 9 日运行，窗口尚未闭合的出院（出院日距离运行日不足 31 天）不进入该月分母，记入异常说明。下月重跑该月批次后再纳入

### 3.7 DRG 组数 `IND-DRG-GROUPS`

- 方向 `high`，`interval_trend`，`grain = year`，`annual_agg = drg_formula`
- 值：该年 `drg_group.drg_code` 去重个数。`weight` 为空的出院患者不产生组，同步时写入 `drg_missing`
- 月事实可以不建。年度批次直接汇总
- 分组器版本写入 `indicator_lineage.filter_summary`
- `fact_member`：分母角色写入有 `drg_code` 的出院键。组清单由血缘摘要列出各组编码和例数

### 3.8 CMI `IND-DRG-CMI`

- 方向 `high`，`interval_trend`，`year`，`drg_formula`
- 分子：该年 `weight` 非空的权重合计
- 分母：`weight` 非空的出院患者数
- 值 = 分子 / 分母
- 不把 12 个月的 CMI 再平均
- 时间消耗指数、费用消耗指数同一模式：分子为实际住院日或实际费用合计，分母为对应标杆合计，方向 `low`。编码预留 `IND-DRG-TIME`、`IND-DRG-FEE`。种子数据可以后补，测试至少覆盖 CMI

### 3.9 麻醉科医师与手术间比 `IND-ANES-OR`

- 方向 `high`，`all_or_nothing`，`month`，`year_end_snapshot`
- 分子：`staff_month` 中麻醉科医师岗位的 `on_duty_count`
- 分母：`anes_month.or_room_count`。该表全院一行，禁止按科室相加
- 年度取 12 月快照

### 3.10 国家专利数量 `IND-PATENT`

- `collect_mode = manual`，`grain = year`，无 SQL
- 审核通过的 `manual_value` 写入人工批次
- 不产生 `fact_member`。血缘指向补录单 id

### 3.11 二期过程指标

表 `clinical_event` 一期可以是空的。

`IND-SSI` 手术部位感染发生率。方向 `low`。分子：`event_type = SSI` 且能连上首页手术患者的事件，按出院键去重后计为发生。分母：首页手术患者。连不上的写 `ssi_unlink`，不进分子。

`IND-CRIT-TIME` 危急值通报及时率。方向 `high`。分子：`event_type = CRITICAL_VALUE` 且 `qualified = true`。分母：同期该事件类型的全部已对照事件。合格阈值放配置，键名 `critical_value_minutes`，不写进 SQL 字面量。未对照事件写 `event_unmapped`。

### 3.12 明确不在一期样例包

人员支出占业务支出使用二期 `finance_year`：分子 `staff_expense`，分母 `business_expense`。方向按省细则配置，通常为高优。`collect_mode` 为 `manual` 或导入。一期不建指标种子，不参加月结。

## 4. 测试向量

纯函数测试不连接数据库。输入用小数，阈值单独给出。

规模类，高优，阈值 2.0，比较符 `ge`。

| 编号 | 各年值 | 期望合并值 | 期望符合 | 原因码 |
| --- | --- | --- | --- | --- |
| S1 | 2.1 | 2.1 | 是 | pass |
| S2 | 1.5 | 1.5 | 否 | median_fail |
| S3 | 1, 2, 3 | 2 | 是 | pass |
| S4 | 3, 3, 1 | 3 | 否 | last_year_fail |
| S5 | 1, 1, 3 | 1 | 否 | median_fail |
| S6 | 1, 2, 3, 4 | 2.5 | 是 | pass |
| S7 | 4, 4, 4, 1 | 4 | 否 | last_year_fail |

S6 验证偶数个年：中间两个是 2 和 3，中位数 2.5。S4 验证中位数达标但最后一年不达标，不能去找中位数落在哪一年。

连续类，低优，阈值 0.02，比较符 `le`。变好为下降。

| 编号 | 各年值 | 期望合并值 | 期望符合 | 原因码 |
| --- | --- | --- | --- | --- |
| C1 | 0.03, 0.02, 0.01 | 0.02 | 是 | median |
| C2 | 0.01, 0.02, 0.04 | 0.04 | 否 | worst_year |
| C3 | 空, 空 | 空 | 空 | not_applicable |
| C4 | 0.01, 0.05, 0.01 | 0.01 | 是 | median |

C2 后一年变坏两次，取最差（最大）0.04。C4 变坏一次、变好一次，视为非变差，取中位数 0.01。

选用集校验（不进函数，测审批）：

- 一条 `interval_trend` 没有 `target_value` 也没有 `band_json`，审批结果为拒绝。
- 纳入条数 / 国标监测指标条数 < 0.60，审批结果为拒绝。
- 同一 `national_indicator_code` 提交两次，第二次拒绝。

抽查错误率（说明书第 8 节，此处只固定期望）：

- 抽查 10 条，1 条相对偏差达到 0.10，错误率 0.10。触发条件是超过 0.10，所以不触发延期。
- 抽查 10 条，2 条错误，错误率 0.20。数据真实性条款 `compliance = non_compliant`，`score_run.grade = deferred`。
- 病案级主要诊断不一致 100 条，但抽查指标重算偏差都小于 0.10：错误率 0，不延期。

成员清单：

- 构造 1 条科室未对照的手术死亡。`IND-SURG-DEATH` 的 `ALL` 分母含该住院号，`UNMAPPED` 含该住院号，任一已对照科室不含该住院号。全院分母不得因为未对照而变小。
- `empi` 为空的非死亡手术出院：出现在 `IND-SURG-DEATH` 分母，不出现在 `IND-READMIT-31` 的分子和分母，`excluded_count` 至少为 1。
