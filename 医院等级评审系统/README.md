# 医院等级评审演示系统

本地可操作的医院等级评审演示。所有医院、患者、业务数据均为虚构合成数据。当前版本展示指标监测、数据核查、补录审核、前置自评、模拟等次、持续改进、政策登记和审计；模拟结果始终标记试算。

## 启动

环境：Java 17 或以上、Maven 3.9、Node.js 22.18 或24.12以上、npm。首次构建需联网下载依赖。

在工作区根目录双击 `启动演示.cmd`，或执行：

```powershell
.\启动演示.ps1
```

启动器构建前后端，服务就绪后打开 `http://127.0.0.1:18173`。后端为 `http://127.0.0.1:18080`。运行日志在工程 `.runtime/`；后端文件数据库和附件在 `backend/.runtime/`。后台服务隐藏运行，不占用新的可见终端。

已有构建结果时可以快速启动：

```powershell
.\启动演示.ps1 -SkipBuild -NoBrowser
```

停止：双击根目录 `停止演示.cmd`。停止只终止本工程启动且进程身份匹配的服务，保留数据。若端口被其他程序占用，启动器提示错误，不会终止其他程序。

## 推荐演示路线

组会使用的丰富场景、当前数据规模与跨 v1/v2/v3 讲解路线见 [演示数据指南](docs/demo-data-guide.md)。启动时自动补齐场景，保留旧批次、附件与报告；无需重置运行库。

1. 在总览查看灯号分布、章节表现、趋势和待办。
2. 进入指标监测，筛选红灯，打开指标详情，查看公式、科室分布与脱敏分子/分母成员。
3. 在补录审核提交补录并审核，返回指标观察人工覆盖标记。自动值仍保留。
4. 在数据核查分别查看病案差异与条款抽查。病案差异数不参与条款错误率。
5. 在前置自评上传佐证，分别设置符合性和复核状态；复核认可不代表符合。
6. 在模拟等次运行2023–2026年样例试算，查看原因码和年度值，下载该次试算的Word报告。
7. 从指标创建改进单，填写负责人、措施和佐证，按状态推进。真实改善关闭需要后续周期的数据；未恢复关闭需要说明。
8. 切换演示角色，查看领导/科室/信息管理员权限差异。该角色切换仅为演示机制，不是正式身份认证。
9. 在运行页面查看批次和审计，需要重新演示时使用“重置演示数据”。重置将恢复初始业务状态。

## 开发与验证

在工程目录运行 `powershell -ExecutionPolicy Bypass -File scripts/verify.ps1` 可依次完成后端测试与打包、前端测试与构建、演示服务器测试和隔离集成检查。集成检查会使用临时 H2、临时附件目录和随机端口，不污染当前演示库。已有服务运行时，请先停止服务再打包，避免 Windows 锁定 JAR。

```powershell
# 后端，在工程 backend/ 内
mvn.cmd test
mvn.cmd package
mvn.cmd spring-boot:run

# 前端，在工程 frontend/ 内
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run dev

# 轻量演示服务器测试，在工程目录内
node --test scripts/serve-demo.test.mjs

# 使用临时数据库与随机端口完成集成，不写当前演示库
node scripts/integration-check-isolated.mjs
```

集成检查生成的前后两份Word报告位于 `.runtime/qa-report-before.docx` 和 `.runtime/qa-report-after.docx`，用于验证后续业务修改不会改变旧报告的数字。

## 工程结构

- `backend/`：REST、合成种子、计分函数、H2状态持久化、附件、Word报告、业务测试。
- `frontend/`：Vue工作台、TypeScript契约、图表和业务交互。
- `scripts/`：启动/停止、静态服务与API代理、集成检查。
- `docs/demo-design.md`：本轮设计与演示简化。
- `docs/api-contract.md`：唯一接口约定。
- `docs/01` 至 `05`、`policy/`：用户原始资料，保留原文。
- **工作区根目录 `交接文档.md`**：多个AI共同维护的交接入口，继续开发前必须阅读。

## 明确限制

样例指标不代表203条完整国标实施包；省级选用与基线为演示约定。H2保存演示状态，不是生产主题库。不包含真实医院ETL、DRG分组器、生产SQL执行、统一认证或公网部署。需要真实落地时应另行评估。

2023–2026年度值为虚构的完整年演示样本；2026年样本不表示现实中已经取得2026全年数据。

实际通过的检查与运行状态以根目录交接文档为准，不能把本README列出的命令视为已执行记录。
