# 前端实施与接续说明

## 范围

Vue 3 + TypeScript + Vite + ECharts 的中文本地演示工作台。使用深蓝侧栏、浅灰背景、白色数据卡片及蓝青强调色；没有远程字体、图片或外部内容依赖。所有页面持续标记演示、合成数据和试算边界。

- `src/App.vue`：九个导航、工作区骨架、周期与角色切换。
- `src/types.ts`、`src/api.ts`：与 `../docs/api-contract.md` 对齐的类型、角色标头、错误与真实文件下载。
- `src/store.ts`：全局工作区、加载、写入互斥、成功后刷新、角色请求竞态保护、文件上传。
- `src/domain.ts`：组合筛选、百分数/空值显示、条款错误率边界、改进状态推进。
- `src/components/*View.vue`：总览、指标、核查、补录、前置、自评试算、持续改进、政策、运行与审计。
- `src/components/Modal.vue`：通用弹层/抽屉、Esc 关闭、焦点限制与恢复。
- `src/components/EvidencePanel.vue`：真实佐证上传及下载，大小和扩展名预校验。
- `src/components/Chart.vue`：按需加载的 ECharts 图表与容器大小监听。
- `src/styles.css`：工作台视觉与 720 / 960 / 1200 / 1600px 响应规则。

## 已实现交互

1. 总览按返回数据生成监测数量、达标率、章节达标概览、近 12 月趋势、重点指标及待办导航。
2. 指标按章节、状态、采集方式和关键字组合筛选，分页；抽屉提供趋势、科室值、固定年度值、定义和分页脱敏成员。成员只发送 numerator / denominator，不提供未约定的排除成员查询。
3. 病例差异与条款抽查分为独立页签；病例说明可保存，抽查生成新快照并可切换历史。10% 错误率边界单独测试。
4. 人工补录固定全院范围（deptCode=ALL），审核通过/退回均保存后重新读取工作区，保留自动原值提示。
5. 前置结论与工作流分开；系统条款只读；不符合时要求说明及佐证。附件真实上传到后端并可下载。
6. 年度样例试算、历史快照选择、采用确认和真实 DOCX 下载；所有结果明确演示试算及未覆盖 203 条/60% 的限制。
7. 改进任务创建、相邻阶段推进、措施、佐证、后续值和关闭模式；已关闭记录质控可重开。
8. 政策登记采用契约指定 kind/impacts；涉及 scoring_rule 的记录禁止确认。
9. 自动月结重跑、批次历史、审计搜索/分页及输入 `RESET_DEMO` 后重置。

全局角色为 quality / leader / department / information。角色变化清空旧工作区再重取，并阻止迟到旧请求覆盖新角色数据。院级/信息科不开放成员清单，本科默认 CARD。UI 权限只用于展示，真正授权由后端校验。

## 运行命令

在工程 `frontend/` 目录执行，实际环境为 Node 24.12.0、npm 11.6.2。

```powershell
npm ci
npm run dev
```

开发服务只绑定 `127.0.0.1:18173`，严格端口模式。`/api` 代理到 `http://127.0.0.1:18080`。根目录启动脚本由主 AI 维护，使用 `npm run build` 产物和本地代理静态服务，不依赖 Vite 开发服务。

```powershell
npm test
npm run build
```

`build` 先运行 `vue-tsc --noEmit`，再运行 Vite。`package-lock.json` 已生成并保留。

## 限制与后续

- 九模块使用内存中的当前页选择状态；刷新浏览器回到总览。这不影响后端保存的业务记录。
- 测试覆盖关键纯逻辑与接口状态边界；没有单独部署浏览器端到端自动测试框架。
- 附件客户端预检只改善反馈，最终类型、大小及归属由后端验证。
- 不实现生产登录、真实源系统接入或正式等次，不在公网发布。
- 构建目录与依赖目录已忽略，不能提交运行产物。
