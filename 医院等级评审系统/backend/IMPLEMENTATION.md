交付时间：2026-10-29。全部医院、人员、病例、指标事实均为合成数据，所有计分记录 `trial=true`。

## 运行与目录

在本目录执行：

```powershell
mvn test -B -ntp
mvn package -B -ntp
java -jar target/hospital-review-demo-1.0.0.jar
```

默认地址 `http://127.0.0.1:18080`，仅绑定回环地址。默认 H2 文件位于 `backend/.runtime/data/demo.mv.db`，真实上传文件位于 `backend/.runtime/uploads/`。路径相对于启动工作目录，因此应从 `backend/` 启动。首次执行 Maven 可能需要联网下载构建插件或依赖。

## 已实现的约束

- 写入在深拷贝状态上校验，通过后原子保存 H2 再替换当前状态；校验失败不会留下部分业务修改。同一服务进程串行修改，避免重复审核和丢失更新。
- 人工补录只支持契约约定的 `deptCode=ALL`。批准生成独立人工批次，按指标与周期覆盖显示值，保留自动值及原始分子/分母。多指标覆盖共存，重跑不会清除覆盖。成员明细仍对应自动事实，不虚构人工补录的患者来源。
- 分子/分母成员总数与合成事实整数一致，支持全院、科室、分页和固定脱敏住院号。床位、人员、CMI、住院日汇总指标返回空患者清单。领导/信息角色禁止成员明细，科室角色仅可读 CARD；全院报告和管理佐证对科室角色拒绝。
- 月结和抽查支持 `2025-10` 至 `2026-10` 的演示周期。`2026-10` 有固定后续改善样本，可验证“后续周期改善”关闭流程；年度计分独立采用固定年度样本，不把月度补录当成全年事实。2026 年明确标记为完整年模拟样本。
- 连续两个月向坏方向变化也亮红灯。规模类同时检查中位数和所选最后一年；连续类变坏次数多于变好次数时取最差年；空年度不纳入，空结果不生成等次。
- 条款偏差使用首页值作基准，`home=0` 特判；偏差 `>=10%` 为错误，错误条款率仅严格 `>10%` 延期。2026-09 合成抽查为 2/10，2026-10 为 1/10。病案差异不计入条款率，历史抽查只追加。
- 系统真实性条款 `p30` 由最新抽查生成，拒绝人工修改。未知和未接纳前置均提示未完成复核。前置流程分别存储结论与工作流，非符合结论需说明及真实附件。
- 改进必须依次 opened→assigned→doing→evidence_ready→verified→closed。措施和附件是证据就绪后的必要条件；improved 关闭还必须具备后续周期改善值，否则需 not_recovered 和说明。已关闭改进只允许质控 reopen，关闭后禁止直接补附件。
- 政策类型和影响枚举按接口契约校验；信息角色仅可登记，质控可确认。涉及 `scoring_rule` 自动 blocked 且禁止确认。
- 附件限制 5MiB 和允许扩展名；PDF/图片/DOCX 做基本文件签名或 ZIP 结构检查。使用随机内部 ID 作磁盘文件名，原文件名只用于展示，下载强制 attachment 和 nosniff。同名附件按对象递增版本。
- 报告只读取创建 ScoreRun 时保存的年度计算、前置和抽查快照。后续编辑、审核、采纳和抽查不改写报告；ZIP 时间固定，重复导出字节稳定。
- 14 项样例按“资源配置与运行、医疗服务能力与医院质量安全、重点专业质量控制、单病种（术种）质量控制、重点医疗技术临床应用质量控制”五章归类。VTE 是限定目标术种的演示样例，i10 是 ECMO 治疗成功撤机率演示样例；各项提供具体公式和纳入/排除规则，均明确目标与告警线为演示目标、非官方阈值。

## 限制与后续

- 浏览器、根启动器、独立 JVM 重启和与前端联调由主 AI 的 T3 验证；本任务不将它们记为通过。本任务的临时测试进程已关闭，演示部署进程由主 AI 启动器管理。
- `X-Demo-Role` 是可切换的演示角色，不能作为生产认证或安全边界；不连接医院、不发布公网。
- 年度和 DRG 汇总使用固定合成事实，不执行真实 ETL、DRG 分组或真实省级评分；前置标题是演示摘要，不冒充官方条文全文。
- H2 快照只适合单机演示，未实现正式主题库、生产并发扩容、数据库迁移或生产备份。
- 重置清除业务对旧附件的引用，保留磁盘旧上传文件，避免误删。旧文件不能再通过 API 访问；本地空间回收可在服务停止后另行实现受控清理。
- DOCX 已验证结构及内容稳定性，未调用桌面 Word 或 LibreOffice 做分页渲染检查。
